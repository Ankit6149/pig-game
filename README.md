# 🎲 Pig Game

## 📌 Overview
**Pig Game** is a fun and interactive **two-player dice game** built with **HTML, CSS, and JavaScript**. Players take turns rolling the dice to accumulate points, but rolling a **1** resets their round score! The first player to reach **100 points** wins.

## 🚀 Features
- 🎮 **Two-Player Mode:** Play against a friend in turn-based gameplay.
- 🎲 **Dice Rolling Mechanics:**  
  - Rolling any number **adds to the round score**.  
  - Rolling a **1** resets the round score, and the turn switches.  
- 🔄 **Hold Feature:** Players can **hold** their points to add them to their total score and pass the turn.
- 🏆 **Winning Condition:** The first player to reach **100 points** wins the game!
- 🔁 **Restart Button:** Reset the game at any time and start fresh.

## 🛠️ Tech Stack
- **HTML** - Structure of the game.
- **CSS** - Styling for a clean and engaging UI.
- **JavaScript** - Game logic, event handling, and DOM manipulation.
